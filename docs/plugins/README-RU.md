# Плагины для RosPanel

[English version](README.md)

Плагин — это JavaScript, который работает внутри панели. Он реагирует на события, работает
по расписанию, хранит свои данные, обращается к API панели и в интернет — ровно настолько,
насколько оператор разрешил при установке. Плагины в бета-версии.

## Что может плагин

| Задача | Как | Пример |
|---|---|---|
| Реагировать на события: регистрация, оплата, конец подписки, падение сервера | `onEvent` | [new-users](../../examples/plugins/new-users), [notify-discord](../../examples/plugins/notify-discord) |
| Делать что-то по расписанию | `cron` | [users-csv](../../examples/plugins/users-csv) |
| Добавить способ оплаты | `payment` | [lava](../../examples/plugins/lava) |
| Принимать запросы из интернета: магазин, форма, OAuth | `onHttp` | [shop-webhook](../../examples/plugins/shop-webhook) |
| Показать данные в карточке пользователя, кнопки, виджеты на обзоре | `userFields`, `onAction`, `widget` | [email](../../examples/plugins/email) |
| Блоки и тема на странице подписки | `subBlocks`, `theme` | [announcement](../../examples/plugins/announcement), [theme-night](../../examples/plugins/theme-night) |
| Доставлять сообщения тем, кого не достаёт бот (почта, SMS) | `channel` | [email](../../examples/plugins/email) |
| Решать, кого пускать к регистрации, какое устройство привязать, какую цену дать | `beforeSignup`, `beforeDeviceBind`, `quotePrice` | [channel-gate](../../examples/plugins/channel-gate) |
| Кнопки и команды в пользовательском боте | `bot` | [channel-gate](../../examples/plugins/channel-gate) |
| Менять конфиги подписки, которые получают клиенты | `transformSubscription` | — |

## Быстрый старт

Всё нужное встроено в `rospanel`, Node.js не нужен.

```sh
rospanel plugin new my-plugin   # рабочий плагин из шаблона
cd my-plugin
rospanel plugin test .          # тесты
rospanel plugin dev .           # консоль с перезагрузкой при сохранении
rospanel plugin pack .          # my-plugin-0.1.0.zip
```

Zip ставится в панели: **Настройки → Плагины → Добавить**. Или напишите плагин прямо в
панели — см. [редактор](editor-RU.md).

```js
// main.js — панель вызывает то, что экспортировано
export function onEvent(e) {
  if (e.event === "user.created") panel.log.info("новый пользователь", e.data.name);
}
```

## Главное, что нужно помнить

- **Синхронный код.** Все вызовы `panel.*` синхронны. Таймеров нет.
- **Доставка «хотя бы один раз».** Событие может прийти дважды, обрабатывайте его
  идемпотентно.
- **Состояние — в хранилище.** Держите его в `panel.kv`/`panel.db`, а не в переменных: VM
  может перезапуститься между вызовами.
- **Ошибки и повторы.** Исключение — это ошибка: событие доставят снова, а после 10 ошибок
  подряд плагин остановится, пока панель не запустит его снова.
- **Минимум прав.** Просите только нужные права и хосты: оператор видит их до установки.
